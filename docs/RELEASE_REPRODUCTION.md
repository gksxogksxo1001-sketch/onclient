## 2. 새 환경 재현 및 클론 절차 (Clean Environment Reproduction)

기존 작업 폴더(`C:\Users\User\Desktop\한태\onclient`)를 안전하게 보존하고, 프로젝트 외부의 새 빈 디렉터리에서 독립적으로 클론 및 실행하는 절차입니다.

### 2.1. 새 빈 폴더 준비 및 클론 (PowerShell)
```powershell
# 1) 프로젝트 외부의 임시 검증 디렉터리 생성 및 이동
mkdir "C:\Users\User\Desktop\한태\onclient-reproduce-test"
cd "C:\Users\User\Desktop\한태\onclient-reproduce-test"

# 2) 원격 저장소에서 동일 최종 커밋 클론
git clone -b main https://github.com/gksxogksxo1001-sketch/onclient.git .

# 3) 동일 커밋 해시 확인
git rev-parse HEAD
```

### 2.2. 런타임 확인 및 무결성 검증
```powershell
# Node.js 엔진 버전 확인 (v24.19.0 확인)
node -v

# 학생 구현 구문 및 정적 무결성 검사
npm run check
# 또는: node --check student/extension.mjs
```

### 2.3. 재현 실행 및 브라우저 검증
```powershell
# 1) 표준 로컬 서버 실행
npm start
# 콘솔 정상 신호 확인: "케셰브 연결 확인: http://127.0.0.1:5189"

# 2) 브라우저 접속 확인
# 주소: http://127.0.0.1:5189 접속 후 메뉴 및 슬롯 렌더링 확인

# 3) 예제 자료(demo) 실행 검증
# 서버 종료(Ctrl+C) 후:
npm run demo
# 콘솔 정상 신호 확인: "케셰브 예제: http://127.0.0.1:5189"
```

## 4. 데이터 보존 및 격리 계획 (Data Preservation Plan)

1. **기존 프로젝트 원본 보존**:
   * 새 환경 재현 과정은 프로젝트 외부 디렉터리에서 수행되며, 기존 작업 디렉터리(`C:\Users\User\Desktop\한태\onclient`)의 Git 커밋 이력 및 소스코드는 수정·삭제·덮어쓰기 없이 원형 그대로 유지됩니다.
2. **인증 자격 및 설정 격리**:
   * 로컬 설정(`.env`), 임시 세션, 인증 토큰은 로컬 루프백 메모리 및 로컬 보관함에 격리되며 원격 Git 커밋에 포함되지 않습니다.
   * 기존 폴더의 임시 토큰이나 인증 캐시를 새 환경으로 복사하지 않고, 새 환경에서 독립적으로 구동되는 무의존성 구조를 보장합니다.
3. **백업 및 복원 방침**:
   * Git 분산 버전 관리 시스템을 통해 GitHub 원격 저장소(`main` 브랜치)에 모든 단계별 커밋 이력이 영구 보존됩니다.
   * 문제 발생 시 언제든지 특정 커밋 해시로 즉각 롤백(`git checkout`)할 수 있습니다.

## 5. 실제 지원 범위 및 기다림(UNV) 항목 요약

공식 평가 기준에 따라 시연(Demo), 학생 진술(Statement), 모의 검증(Mock Verification)과 실제 외부 원천 연결(Live Production)을 명확히 구분합니다.

* **실제 검증 완료 범위 (Verified)**:
  * 단일 Node.js 24.19.0 환경에서 무의존성으로 서버 구동 및 로컬 루프백(`127.0.0.1:5189`) 통신 완료.
  * `student/extension.mjs`의 7개 화면 렌더링 함수가 모든 계약 조건(텍스트 상태 분기, DOM API 사용, 보안 필드 제거, 미실행 안내)을 충족함.
  * 정적 코드 검증(`npm run check`) 및 단위 테스트 완료.
* **기다림 / 미완료 상태 (UNV - Unverified)**:
  * **실제 엔드포인트 조치 집행 (19단계 실집행)**: 실제 기업 네트워크 환경의 SDP 에이전트/방화벽을 통한 기기 격리 및 세션 철회는 외부 인프라 연동이 필요하여 현재는 클라이언트 화면 계약(ACK와 효과 분리)까지만 구현·검증됨.
  * **실운영 AI 게이트웨이 라이브 호출**: 학생 계정 전용 실서버 AI 모델 프로비저닝은 운영 측 일정에 종속되므로 로컬 모의 및 계약 검증 상태로 대기.
  * **v1.0 정식 릴리스**: 위 실집행 연동 및 22단계 공식 최종 수료 확정 전까지는 `v0.2.11-candidate` 상태를 유지함.
